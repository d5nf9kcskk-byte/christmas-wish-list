💌 After Christmas: the great unmasking

🧰 Adding from other stores

One-click adding from Amazon, Etsy, and other stores. One-time setup, per device. Open Setup only when you need it; the rest of the time this stays tucked away.

Pick your device:

  • 💻 Computer with Chrome: the tree extension, in its section below. Nothing can block it; it is the one to use for Amazon. The bookmark button right under this box also works, on pages that allow it.
  • 🤖 Android phone: Add to Home screen once, then Share → Wish List from any store app. See the Android section below.
  • 🍎 iPhone: download the ready-made shortcut in the iPhone section below (one tap to install). It lives in the Share button, so it works in portrait mode, unlike the bookmarklet. Paste-a-link also always works.

The bookmark (any desktop browser). Adding from Etsy, Amazon, Nike, or another store that blocks lookup? Drag this button to your bookmarks bar. Then open the item's own page in that store, not a search results or shop page, and click the bookmark there. It reads the name, photo, and price from the page you are looking at and opens your list with everything filled in. Already had the bookmark? Delete the old one and drag this new version: it opens the tab first, so Chrome's popup blocker cannot silently stop it, and if a new tab is blocked anyway it opens your list in the same tab instead of doing nothing.

🎁 Add to my Wish List

Works in desktop browsers. On a phone, paste the link as usual and use the photo tip in the add form.

Clicked the bookmark on Amazon and nothing happened?
  1. First make sure you have the new version: delete the old bookmark, then drag the button above up to the bookmarks bar again.
  2. Test the new bookmark on a plain page, like any Wikipedia article. If your list opens there, the bookmark is installed correctly.
  3. If it does nothing everywhere: right-click the bookmark, choose Edit, and look at the address. It has to start with javascript: and be very long. If it starts with https or is short, the drag did not take. Delete it, tap Copy bookmarklet code above, add a bookmark by hand, and paste the code in as its address.
  4. If it works on other pages but not on an Amazon item page, that page is refusing to run it; Amazon does this on some pages now. Workaround for that item: copy the item's link, come back here, tap + Add wish, and paste the link. The name usually fills in; if the photo does not, use the photo tip inside the add form.
Using Chrome on a computer? The extension never gets blocked (best for Amazon)
  1. Download wish-list-extension.zip and unzip it. You get a folder called extension.
  2. In Chrome, open chrome://extensions and turn on Developer mode (top right).
  3. Click Load unpacked and choose that extension folder.
  4. Pin the little tree 🎄 to the toolbar. From then on, on any item page, Amazon included, one click on the tree opens your list with the name, photo, and price filled in. No bookmark, no popup blocker, nothing for the store page to refuse.

One quirk: Chrome may show a "developer mode extensions" notice when it starts. It is just a reminder that you installed it yourself; dismiss it and the tree keeps working.

On an Android phone: add from the Share button
  1. Open this list in Chrome, tap the ⋮ menu, and choose Add to Home screen (or Install app).
  2. After that, on any item page or in a store app, tap Share and choose Wish List.
  3. Your list opens with the add form ready. The link always comes across; the name comes too when the store provides it, and the photo fills in for stores that allow lookup.
🍎 On an iPhone: the easy way (Shortcuts, works in portrait)

The Safari bookmarklet is awkward on an iPhone because the bookmarks panel only slides in beside the page in landscape; in portrait you cannot see your bookmarks and the page at the same time. Apple's own Shortcuts app fixes it: the shortcut lives in the Share button, so it works in portrait and landscape, in Safari and in Chrome.

Easiest: download the ready-made shortcut. 📥 Download Add to Wish List (.shortcut)

  1. On your iPhone, tap the download link above in Safari. It downloads the shortcut file.
  2. Open the downloaded file (tap it in the download bar, or find it in Files → Downloads). Shortcuts opens and shows what it does.
  3. If iOS blocks it as an untrusted shortcut, open Settings → Shortcuts and turn on Allow Untrusted Shortcuts, then open the file again.
  4. Tap Add Shortcut.
  5. Use it: on any item page in Safari, tap Share → Add to Wish List. Your list opens with the name, photo, and price filled in. The first time, tap Allow when it asks to run on that page.

If Shortcuts refuses the file, build it by hand in two minutes instead:

  1. First, once: open Settings → Shortcuts → Advanced and turn on Allow Running Scripts. (On newer iOS, it is under Settings → Apps → Shortcuts → Advanced.)
  2. Open the Shortcuts app, tap +, and add the action Run JavaScript on Web Page.
  3. Tap Copy Shortcut code below and paste it in place of the action's sample script. The code ends with completion(...); that line is what hands the result back, so keep it.
  4. Add a second action below it: Open URLs, and set its address to the result of the JavaScript action (it shows as "Run JavaScript on Web Page" or "Shortcut Result").
  5. Tap the shortcut's name, call it Add to Wish List, open its details (ⓘ), and turn on Show in Share Sheet.

Once you have it working on your phone, you can send it to family in one tap: in the Shortcuts app, long-press it → Share → Copy iCloud Link, and send them that link.

On an iPhone (Safari): the bookmarklet way, one time
  1. Tap Copy bookmarklet code above.
  2. In Safari, open any page and add a bookmark named Add to Wish List (Share button, then Add Bookmark).
  3. Open Bookmarks, tap Edit, tap that bookmark, delete what is in the address field, and paste the code there. Save.
  4. From then on: open the item's own page, open Bookmarks, and tap Add to Wish List. Your list opens with name, photo, and price filled in.
  5. In Chrome on iPhone, a bookmarklet made on a computer with the same Google account syncs over by itself. To run it, type its name in the address bar and tap the bookmark in the suggestions; do not press Enter.
From the Etsy app

The bookmarklet cannot run inside an app. In the Etsy app, tap Share and Copy Link, then paste the link into the add form here. The name and store fill in; for the photo, open the same link in your phone browser, long-press the photo, open it in a new tab, and copy that address into Image URL.
